================================================================================
WHAT THIS PROJECT DOES
================================================================================

Extracts and normalizes tower component cost data from Excel files.

INPUT:
  - Source Excel: Input Sheet Sales Calculation Tower v26.1 USD
  - Sheet 1: TS SC v26.1 (400 steel towers, complex matrix structure)
  - Sheet 2: TCS_MB SC v26.1 (108 concrete/hybrid towers, flat table)

OUTPUT:
  - Single consolidated Excel file: output/tower_components_extracted.xlsx
  - 133,588 rows of component cost data
  - 14 components x 11 regions x 3 years (+ variations)
  - Currencies: Cost_EUR (Euros) and Cost_USD (Dollars)

================================================================================
CONFIGURATION
================================================================================

File: config.json

Key settings:
  * input_file_path: Path to source Excel file (EDIT THIS if needed)
  * output_file_path: Where to save result
  * source_sheets: Names of Excel sheets to read
  * target_years: Which years to process (2026, 2027, 2028)
  * canonical_regions: List of 11 regions

================================================================================
CUSTOMIZATION
================================================================================

Change Input File:
  1. Edit config.json
  2. Update input_file_path to new Excel location
  3. Run: python scripts/extract_tower_data.py

Add New Years:
  1. Edit config.json
  2. Add to target_years: [2026, 2027, 2028, 2029]
  3. Run extraction

Verify Output:
  python scripts/verify_output.py

================================================================================
TECHNICAL DETAILS
================================================================================

Language: Python 3.7+
Dependencies:
  * openpyxl (3.10.10) — Excel file handling
  * pandas (2.2.0) — Data manipulation & pivoting

Extraction Logic:
  TS SC v26.1:     Read headers (rows 1-3, 7), extract by column pattern
  TCS_MB SC v26.1: Unpivot flat table (rows 86+)
  Combine:         Concatenate datasets, normalize names & types

Data Quality:
  * No blank Year_Production values
  * All regions canonicalized
  * Component names normalized (Tower Shell, not tower shell)
  * Currencies separated into distinct columns

File Size: ~4 MB (Excel with 133,588 rows)
